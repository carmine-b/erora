- File: `Adalogger/adalogger_featherwing.step` (or .brd for EAGLE)

### OLED FeatherWing 128x64
- File: `OLED_Display/oled_featherwing_128x64.step`
- Source: [Adafruit CAD Parts](https://github.com/adafruit/Adafruit_CAD_Parts)

## File Format Notes

- All models are in **STEP** format (`.step` or `.stp`)
- Compatible with most CAD software (Fusion 360, FreeCAD, SolidWorks, AutoCAD, etc.)
- Large files may use Git LFS if over 100MB
